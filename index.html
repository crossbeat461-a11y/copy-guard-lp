増えた競合コピーを、確認してから片づける Sync clutter, reviewed before you delete it

CopyGuard は、iCloud・Dropbox・Remotely Save・Syncthing など、Obsidian Sync 以外の方法で同期しているときに増える「競合コピー」「空ファイル」「一時・破損ファイル」を見つける整理プラグインです。見つけた項目は、選んだものだけ隔離フォルダへ移すだけ。削除は別の確認ステップで、既定は「削除ミスをおこさない」です。無料（MIT）。

CopyGuard is a tidy-up plugin for vaults synced with iCloud, Dropbox, Remotely Save, or Syncthing — the setups without Obsidian Sync's built-in conflict merging. It finds sync-conflict copies, empty files, and leftover temp files, then moves only what you approve into a quarantine folder. Deleting is a separate, confirmed step built to avoid delete mistakes. Free & MIT.

Only pairs with a nearby original

機能対象事項・非機能対象事項

In scope — and out of scope

役割をはっきりさせた、小さくて正直なツールです。

A small, honest tool with a clearly defined job.

機能対象事項 ✓ Does

  • 競合コピー・空ファイル・一時ファイルの検出（名前と大きさだけで判定）
  • 選んだ項目だけを隔離フォルダへ移動
  • 隔離フォルダの最終削除は、必ず確認してから（既定は削除ミスをおこさない）
  • 削除先はアプリの「削除したファイル」設定に従う
  • Detect conflict copies, empty files, and temp files (by name and size only)
  • Move only the items you select into a quarantine folder
  • Ask for confirmation before any final delete (default is built to avoid delete mistakes)
  • Follow the app's own “Deleted files” destination setting

非機能対象事項 △ Out of scope

  • 競合コピーの中身を自動でマージ（結合）する
  • iCloud / Dropbox / Syncthing などがコピーを作るのを止める
  • 確認なしでの自動削除
  • 判定の完全な正確性の保証（誤検出の可能性があります）
  • Automatically merge the contents of conflict copies
  • Stop iCloud / Dropbox / Syncthing from creating more copies
  • Delete anything without asking first
  • Guarantee perfectly accurate detection (false positives are possible)

インストール方法

How to install

いまは GitHub Releases から手動でインストールします。コミュニティ掲載が完了すれば、そちらの検索からもインストールできます。

Install from GitHub Releases for now. Once community listing is complete, you'll also be able to search and install from there.

1

最新リリースを開く

Open the latest release

GitHub の Releases から main.js、manifest.json、styles.css をダウンロードします。

From GitHub Releases, download main.js, manifest.json, and styles.css.

2

フォルダに置く

Put them in a folder

Vault の .obsidian/plugins/copy-guard/ に3ファイルを置きます（フォルダがなければ作成）。

Place the three files in .obsidian/plugins/copy-guard/ (create the folder if needed).

Enable, then scan

設定 → Community plugins で CopyGuard をオン。リボンの ⧉ アイコン、またはコマンド「Open CopyGuard」。

Settings → Community plugins → enable CopyGuard. Click the ⧉ ribbon icon, or run Open CopyGuard.
